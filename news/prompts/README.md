# Промпты новостника

Модель в конвейере пишет только **одну вводную фразу** над шаблонной статистикой. Цифры, фамилии и счёт идут из данных, модель их не трогает. Фразу проверяет `guard.check_lead`: числа и числительные, чужие фамилии и клубы, несверяемые слова («впервые», «рекорд», «подряд»), слухи, разметка.

## Профили

Модели разные по силе, поэтому промпт — под модель, а не один на всех (`PROFILE` в `news/llm.py`):

| Файл | Для кого | Устройство |
|---|---|---|
| `lead.md` | сильные модели (Claude) | роль и тон канала → как выбрать сюжет → жёсткие правила с объяснением → разбор примеров «хорошо / плохо и почему» |
| `lead.compact.md` | слабее (GigaChat, YandexGPT) | короткие пронумерованные запреты капсом → один алгоритм выбора сюжета → только образцы правильных фраз → «Фраза:» в конце как якорь ответа |

Ответ модели чистится (`_clean`): берётся первая непустая строка, снимаются подписи вроде «Вот фраза:» и кавычки.

## Как менять промпт

1. Правка — в файле профиля, не в коде.
2. Прогон: `python -m news.eval run --providers claude_cli,gigachat --runs 2` на сохранённых реальных постах (`news/fixtures/`, пополнять: `python -m news.eval save <с> <по>`).
3. Принимаем, если доля прохода гарда не упала, а фразы в отчёте `news/out/eval_*.md` прочитаны глазами. Гард не проверяет смысл («кто победил», «забивал»), поэтому выборочная сверка фраз с фикстурой обязательна.
4. Результат — строкой в журнал ниже.

## Уроки

- **Пример в промпте модель копирует дословно.** Образец «Главный герой ночи — …» дал этот зачин в половине фраз. Теперь примеры с разным построением плюс прямое правило «не открывай штампом».
- **Запрет склонять фамилии делал русский деревянным** и ничего не защищал: гард ищет фамилии по основе слова. Склонять можно, менять написание нельзя.
- **Числа словами гард сверить не может**, поэтому любые числительные во фразе запрещены целиком — и в промпте, и в гарде.
