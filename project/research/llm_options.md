# Языковая модель для новостника: варианты и экономика

> 25.10.2026 · к вопросу владельца «API или Claude Code на VPS, или другие модели — что экономически оправданнее?»
> Роль модели в конвейере — одна вводная фраза к шаблонному посту (`news/rewrite.py`). Цифры и фамилии модель не пишет, их проверяет `news/guard.py`.

## Допущения по нагрузке

- Один вызов: ~1 500 токенов на вход (пост + правила) и ~300 на выход (фраза + размышления модели).
- **MVP:** ~60 вызовов в месяц (2 в день: «Ночь наших» + дайджест AHL).
- **Рост:** ~900 вызовов в месяц (30 в день: сеть каналов, посты по событиям).

## Вывод

**Деньги за токены ничего не решают.** Во всех вариантах это от копеек до ~1 000 ₽ в месяц даже при росте. Решают три вещи: **доступ** (легальность и оплата из РФ), **надёжность** (что будет, если провайдер отвалится) и **качество русского** во вводной фразе.

**Рекомендация:** сделать слой модели сменным (`NEWS_LLM=claude_cli | gigachat | yandexgpt | anthropic_api | none`). На теневой неделе прогонять два варианта на одних и тех же постах:
1. **Claude Code на VPS** — основной. Бесплатный, уже работает, качество проверено.
2. **GigaChat** — запасной и легальный в РФ. Бесплатен в рамках Freemium, оплата в рублях, если понадобится.

Сравнение — по доле фраз, прошедших гард, и по выбору владельца при ✅. Шаблон без модели (`none`) остаётся страховкой всегда.

Anthropic API имеет смысл только при наличии зарубежной карты и желании отвязать конвейер от лимита подписки. По условиям региона он ничем не лучше подписки.
