## Продолжить

1. Прочитать [процедуру/отчёт пилота](../process/source-shadow.md), [план](../planning/source-pilot-2026-11-01.md), [результат запуска](../planning/source-pilot-launch-results-2026-11-01.md).
2. После фактического периода выгрузить report/SQLite, разметить полезность новых кандидатов, ложные слияния/пропуски, обновления и задержки. Не объявлять недельный эксперимент успешным до данных. Полноту NHL ID и разные UTC-даты эпизодов улучшать по наблюдениям.
3. Автопубликацию новых лент включать только после оценки пилота. Следующая продуктовая рубрика в бэклоге — «Неделя наших».

Отчёт сейчас: `docker exec hockey-shadow python -m news.shadow_runner report`; после завершения — `docker compose --profile source-shadow run --rm --no-deps shadow python -m news.shadow_runner report`. Ручной tick параллельно serve не запускать.

Откат пилота: остановить только shadow, выключить маркер enabled до следующего CI; SQLite/JSON сохранить. Это исполнимо без сборки/сети. Общий откат образа новостника — штатный Actions news_image=previous (предыдущий рабочий образ); при образе без модуля deploy останавливает пилот.
