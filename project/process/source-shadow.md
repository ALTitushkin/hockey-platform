# Теневой пилот источников и дедуп

01.11.2026, ветка `release/source-dedup-20261101`. Эта возможность изолирована от публикации и текущего `stories_state.json`.

## Что работает

- `news/source_shadow.py`: RSS2 DFO/AHL, GUID/link, полный content:encoded или description; предел 2MiB/100 записей. Вложения и внешние статьи не загружаются. DTD/entities и UTF16 отвергаются до XML-разбора.
- `news/source_dedup.py`: source+ID, канонический URL (удаляются только известные tracking-параметры), SHA256 нормализованного текста. Числа, отрицания, содержательные query-параметры сохраняются. История URL не теряется при смене GUID.
- Совпадение текста разных документов действует только в пределах72часов, чтобы независимое событие через недели не подавлялось навсегда. Часы SQLite ledger можно подменять в тестах.
- Событийный контракт `Event`: стабильные NHL ID участников, действие, ID/дата эпизода и факты. Разная формулировка одинаковых фактов — дубль; expected→confirmed, новый срок/сумма — update; новое действие/эпизод — new. Опровержение/исправление старой версии включает явный `revision` в facts.
- SQLite сохраняет все версии/происхождение в одной транзакции. `observe` не означает `published`; Telegram/MAX и доставка этим модулем не затрагиваются.

## Реальная проверка

После проверки robots выполнен один GET каждой публичной RSS-ленты, для AHL выдержан интервал10сек. DFO:25 записей/182282байта; AHL:10/43585. Оба ответа успешно разобраны новым парсером. Повторный прогон тех же файлов:25/25 и10/10 duplicate. [Метаданные проверки](releases/source-shadow-2026-11-01.json). Полные RSS остались в игнорируемом `news/out/source-pilot/`, в git их нет.

Офлайн-тесты:18 для дедупа и4 для RSS. Проверены смена URL, новые факты, отрицания, временное окно, перезапуск БД, небезопасные XML/ссылки. QA и security review выполнены; замечания об истории URL и бессрочном текстовом дедупе исправлены.

## Повторить на сохранённом файле

```powershell
python -m news.source_shadow dfo news/out/source-pilot/dfo.xml --db news/out/pilot.sqlite
python -m news.source_shadow ahl news/out/source-pilot/ahl.xml --db news/out/pilot.sqlite
```

Сохраняются хеши и ссылки; копии текстов и промпты не пишутся в ledger. Модель не используется. CLI не имеет сетевого режима.

## Что ещё требуется

Автоматическое извлечение полного Event из свободного текста пока отсутствует. Без него разные пересказы одного события могут остаться разными кандидатами. Неполные/неуверенные факты нельзя использовать для автоматического подавления новостей. Статистические ключи должны включать модель/метрику, сезон, тип матча, ситуацию и период.

Регулярный семидневный сбор и подключение в автопубликацию не включены. Перед ними: подтвердить условия регулярного использования RSS, добавить планировщик с conditional GET/15мин и robots/crawl-delay, ограничить host/redirects сетевого клиента, фиксировать новые/повторы/обновления и разбирать ложные слияния. Не включать ESPN/THW и не обходить403/challenge. Права на копирование статей и фотографий RSS не даёт; пилот не перепубликует их.
