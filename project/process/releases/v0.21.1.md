# v0.21.1 — актуальность и закрытие очереди

07.11.2026. Локально286 проверок (255 unittest+26news+5delivery), Ruff чистый.
QA15 новых lifecycle-регрессий, replay метаданных6 исторических задач, security замечания
закрыты.46 core-тестов идут на workspace runtime без эскалации. Даты тестов заданы явно.

Правила: night/league до конца даты выпуска МСК; weekly7дней; tonight до первого
подтверждённого начала матча; ожидаемое возвращение по expires_at. Отсутствие окна
здоровья → needs_revalidation; статья без source_snapshot → legacy_review. Подтверждённый
контракт с источником без искусственного общего TTL. Эти правила не исправляют старый текст.

Владельцу: `/queue`, `/review DATE KIND`; в ревью кнопки закрытия «устарело»/«не по теме».
Для своей причины: `/close DATE KIND VERSION причина`. Решение привязано к версии.
Опубликованное/частичное/неопределённое не закрывается как неопубликованное.
Старая причина сохраняется; удалений файлов и массового закрытия при миграции нет.

Миграция только вычисляет статусы из существующих JSON, новой схемы таблиц нет.
editorial_closed — добавочное поле. Закрытие также ставит совместимый rejected=true:
v0.21.0 блокирует его после отката. Старый образ не знает новых сроков, поэтому старые
неистёкшие по прежним правилам задачи требуют ручной сверки. Данные/историю не удалять.
Проверен импорт образа e2384c6b4090 (v0.21.0), он сохраняется как previous.

Не реализовано в этом пакете: редактирование фактов из Telegram и получение новой версии
источника по кнопке. Они остаются отдельным проверяемым сценарием; legacy нельзя просто
«разрешить» кнопкой в обход доказательств. Сегментация Status Report — следующий пакет.
