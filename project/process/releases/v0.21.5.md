# Релиз v0.21.5 — события и серии в ночных итогах

## Объём

- Статистика игроков и вратарей остаётся на карточке; подписи ночных итогов показывают значимые события без повторения цифр с изображения.
- В постматчевые итоги добавляются продолженные результативные/голевые серии и значимые прерванные серии на основе полного журнала игр НХЛ.
- В «Ночи наших» кандидаты — игроки наших команд; в общей лиге — топ-10 по очкам и игроки с другими найденными событиями.
- Предматчевые интриги уже показывают серии наших игроков и клубов; этот релиз сохраняет их текущий путь и пороги.

## Проверки и ограничения

- Автопроверка не пропускает серии без полного `game-log/now`, записи текущего матча и совпадения голов/очков с официальным бокс-скором.
- Серии считаются только для регулярного чемпионата. Если источник недоступен, неполон или отстаёт, пост собирается без утверждения о серии.
- Полные локальные release gates и CI должны пройти до выката.

## Откат

Схема и данные базы не меняются. При проблеме после выката: GitHub Actions → CI/CD bot → Run workflow → `news_image=previous`. Проверить healthcheck бота/новостника и логи деплоя; теги релизов не перезаписывать.

## Результат выката

Заполняется после CI и production-проверки: merge commit, тег, workflow, healthcheck, фактический image и результат проверки публикационного цикла.
