# Замена Claude на Codex — проверка 31.10.2026

## Что подготовлено

`news/codex_provider.py` запускает закреплённый Codex CLI 0.166.0 с GPT-6 Luna через подписку ChatGPT.
Авторизация на VPS проверена в отдельном контейнере, перенесена по SSH без вывода токенов.
Файл авторизации требует прав 600, каталог — 700 и владельца UID 1000. Не добавлять его в git,
Docker build context или отчёты. Не монтировать личный полный каталог `.codex` в сервис.
Доступ подписи хранится отдельно в `news-codex-auth/`; write-доступ нужен для обновления токенов.

Из нового Dockerfile удалены установка и бинарник Claude. Новый multi-stage образ копирует только
native Codex из npm-пакета: Node/npm в финальный образ не попадают. Compose переключён на `codex_cli`.
Исторические eval-записи Claude сохранены. Глобальные установки других проектов не удалялись.

Модель получает только текст новости, словарь имён и короткие редакторские правила. Шаблонные
цифры и оформление остаются в коде. Вызов без shell-интерполяции, cwd временный, пользовательский
конфиг и каталог навыков не загружаются в контекст. Инструменты отключены; tool events отвергаются.
Окружение дочернего процесса содержит только allowlist и не содержит токенов Telegram/MAX/API.
Лимит промпта — 20000 знаков; превышение возвращается на ревью, обязательные факты не обрезаются.
Таймаут — 120 секунд; при отказе провайдера общий cooldown 30 минут. Повторы одного инфоповода
идут с задержкой 30/60/120/240/360 минут, уведомление — не чаще раза в 6 часов.

## Проверено измерением

Базовое наблюдение VPS: доступно 1896 МБ из 3889 МБ RAM, swap 0, диск 24%, load 0.16.
Рабочий новостник использовал 45.88 MiB; его исторический memory.peak — 211427328 байт.
Это не сопоставимый A/B-тест с новым CLI: различаются время и сценарий.

Пилот: отдельный non-root read-only контейнер без Telegram-токена и публикаций; лимиты 384 MiB RAM,
384 MiB memory+swap, 1 CPU; один последовательный поток, тот же Python/Pillow образ.
Последний прогон трёх реальных источников NHL.com:

| Показатель | Измерено | Критерий |
|---|---:|---|
| Пик памяти | 111788032 байта = 106.6 MiB | ниже 384 MiB |
| Swap | 0 | 0 |
| OOM / OOM kill | 0 / 0 | 0 |
| CPU всего за 3 пересказа | 1.82 CPU-секунды | без давления на соседей |
| Время одного ответа | 2.71–3.17 секунды | ниже 120 секунд |
| Входные токены | 6940–8330 на запрос | измерять, не оценивать по длине текста |
| Выходные токены | 42–61 на запрос | короткий пересказ |
| Проход гарда фактов | 3/3 | замечания блокируют отправку |

Один текст потребовал ручной проверки написания имени. Чистый гард не является доказательством
всех смысловых связей; пересказы сверены с исходниками. В повторной редакторской итерации убраны
повторы заголовка. Длинная Status Report раньше теряла обязательный абзац после первых 5000 знаков;
теперь он сохраняется целиком. Новостные исходники/полные тексты находятся только в ignored `news/out/`.

Пилот суммарно включал 12 серверных вызовов в нескольких итерациях. Это небольшой последовательный
тест, а не недельный soak test или имитация дедлайна. Лимит 384 MiB не уменьшаем до наблюдения в проде.
Сырой последний результат локально: `news/out/server-pilot/server-pilot/` (ignored).

## Лимит подписки

Codex CLI использует общий лимит подписки. Процент расхода по одним токенам не вычисляется:
влияют модель, кэш, reasoning и режим обслуживания. Включены low reasoning и обычный режим,
без дорогих инструментов и второго редакторского LLM-прохода. Дневного ограничения числа постов
не введено; очередь сохраняет новости при отказах. Метрики без текста/секретов — `codex_usage.json`.

Ориентир по измеренной выборке: 10 пересказов — около 69–83 тыс. входных токенов и 420–610 выходных,
без учёта повторов и вводных фраз регулярных рубрик. Это оценка объёма, не обещание процента квоты.
Официальные сведения: [режим скриптов](https://learn.chatgpt.com/docs/non-interactive-mode),
[авторизация](https://learn.chatgpt.com/docs/auth?surface=cli),
[расход подписки](https://learn.chatgpt.com/docs/pricing?codex-pricing-plans=individual).

## Статус выката и следующий шаг

**Прод не переключён. Новый финальный Docker-образ не собран и не проверен.** Локальный Docker
Desktop сообщил `wslUpdateRequired`; `wsl --update --web-download` завершился с кодом 1.
Docker Desktop после неудачного старта останавливается. На общем VPS образ не собирали
по стандарту «Инфра-и-масштабирование». Рабочий контейнер не изменяли, публикаций из пилота нет.
Коммиты, push и merge не выполнялись.

Следующий шаг — собрать образ вне общего VPS (штатный CI), прогнать smoke test из workflow,
затем выполнить штатный релиз с сохранением previous. Перед стартом создать `news-codex-auth/`
с правильными правами, проверить `codex login status`, убрать переменные `CLAUDE_CODE_OAUTH_TOKEN`
и `NEWS_CLAUDE_MODEL` из серверного `news/.env` без вывода значений. После выката проверить отсутствие
Claude в образе, состояние/метрики, отсутствие дублей и доставку свежего инфоповода. Старые seen
автоматически не сбрасывать. Новые внешние источники пока не включать: проект дедупа в отдельном
[исследовании](../research/reports/Источники%20хоккейных%20новостей%20без%20дублей.md).
