### Добавлено (новостник, 26.10.2026)
- «⚡ Инфоповоды» (`news/stories.py`): лента NHL.com раз в 15 минут, вид новости по заголовку (обмен, контракт, крупная травма — вся лига; вызов, отправка, вейверы, возвращение — только наши). Релиз клуба ждёт до часа текст NHL.com — в нём контекст. Пересказ — модель по `prompts/story.md`, гард: числа только из текста (и словами — «eight»), без латиницы, герой и наши названы, незнакомые имена — «👀 проверь». Черновики владельцу; сбой пересказа — владельцу сообщение со ссылкой
- Инфоповоды: автопубликация (`NEWS_STORIES_AUTO=1`, решение владельца после первых черновиков); у вратарей — строка «🥅 Фамилия · сезон: матчи, КН, %ОБ» из API НХЛ (текущий сезон или последний сыгранный)
- Инфоповоды с картинкой (`card.render_story_card`, 1080×1350): вид новости, логотип клуба (у обмена — оба и стрелки), герой с плашкой «НАШ ИГРОК», заголовок поста, у вратаря — КН и %ОБ. Герой без тега — по ссылке в тексте и фамилии в заголовке, клуб без тега — из заголовка. Логотипы перекачаны в 640 px (`logos.SIZE`), на карточке срезаются прозрачные поля
- Реестр наших: Александр Никишин (в сезоне ещё не играл — `sync-registry` его не видел)
- Живой реестр наших (`news/registry.py`): каждое утро в 08:00 — сверка с составами 32 клубов (родина RUS/BLR) и статистикой сезона (гражданство); новые — с именем из Wikidata, сменившие клуб и уехавшие из НХЛ — отметкой `team` (запись не удаляется); изменения — владельцу. Из инфоповода новый наш добавляется сразу. Нет русского имени — владелец присылает `/name <id> Имя Фамилия`. Изменения сервера — `news-runtime/registry.json` поверх `data/players.json`. Первая сверка нашла пропущенных Проворова и Гребёнкина
- «Ночь наших»: у вратарей %ОБ за матч — «30 из 33 (90,9%)», сухой матч — «100%»; цифры процента — в фактах гарда
- `llm.ask` — общая цепочка провайдеров; провайдеры отдают ответ целиком, обрезка до фразы — только во вводной
